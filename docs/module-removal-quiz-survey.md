# 퀴즈·설문 제거와 기존 설치 처리

2026-09-05부터 `quiz`와 `survey`는 saanraan 저장소와 설치 번들에 포함하지 않는다. 콘텐츠와 커뮤니티에 기능을 이관하지 않는다. 현재 번들 모듈 수는 30개다.

## 코드와 요청 흐름

- 두 모듈의 PHP, JavaScript, CSS, 테마·스킨, 설치 SQL, 업데이트 파일, 관리자 메뉴와 공개 계약을 제거한다.
- 신규 설치에서 두 모듈을 선택할 수 없다. 해당 공개/관리자 route와 UI-KIT도 제공하지 않는다.
- 콘텐츠·커뮤니티 레이아웃의 지원 대상, 임베드 대상, 리액션 대상, 본인확인 목적, 자산 소비자 안내에서 두 모듈을 제외한다.
- 전용 fixture와 퀴즈 E2E smoke 및 `--run-quiz-smoke` 옵션을 제거한다. 남은 모듈의 검사와 개인정보 계약은 유지한다.
- 자산·결제·감사 기록의 과거 source 표시명, 일반 아이콘 이름, 다른 모듈의 이미 적용된 SQL 업데이트는 역사적 기록으로 남을 수 있다. 이는 기능 제공이나 재설치를 의미하지 않는다.

## 기존 설치의 배포 전 처리

이 변경은 기존 DB나 업로드 파일을 자동 삭제하지 않는다. 기존 설치에서 파일만 덮어쓰면 이전 모듈 디렉터리가 남을 수 있으므로 배포 파일 목록에서도 두 디렉터리를 제거해야 한다.

1. 기존 코드가 있는 상태에서 DB와 저장소를 백업하고 두 모듈의 사용 데이터, 개인정보 처리 의무, 보상 지급·회수·실패 건을 확인한다. 필요한 export와 개인정보 정리는 제거 전 계약으로 완료한다.
2. 초기화면, 레이아웃, 사이트 메뉴, 배너·팝업 대상, 본인확인 제공자 목적, 쿠폰 발급 대상, 본문 링크·임베드 등 저장된 참조를 확인하고 운영자가 남은 기능의 대상으로 변경하거나 제거한다. 다른 모듈의 설정을 자동 치환하지 않는다.
3. 두 모듈을 관리자에서 비활성화한 뒤 새 코드를 배포하고 `modules/quiz`와 `modules/survey`가 배포 서버에서도 제거됐는지 확인한다. 새 버전은 두 모듈의 관리·export·cleanup 화면을 제공하지 않는다.
4. 운영 기록은 보존 목적과 기간에 따라 별도로 관리한다. `sr_quiz_*`, `sr_survey_*` 테이블, 저장소 파일, 모듈 설치 기록의 영구 삭제는 이 커밋에 포함하지 않으며, 백업·참조·보존 의무를 검토한 별도 작업으로 수행한다. 공통 자산·결제·감사 원장을 함께 삭제하지 않는다.
5. 설치된 상태에서 이전 공개/관리자 URL이 더 이상 처리되지 않고, 콘텐츠·커뮤니티와 관리자 화면이 정상 동작하는지 확인한다. 미설치 상태의 설치 화면 응답은 이 확인을 대체하지 않는다.

DB/개인정보 기준은 [구현 스냅샷](implementation-snapshot.md), [개인정보 계약 매트릭스](privacy-contract-matrix.md), [개인정보 처리활동 기준](privacy-processing-records.md)을 함께 따른다. 과거 `docs/records/`와 계획 문서의 두 모듈 설명은 당시 기록이며 현재 기능 목록이 아니다.

## 검증

`check-service-module-removal.php`는 제거된 모듈의 설치·route·layout·리액션 연결이 되살아나지 않는지 검사한다. 전체 점검은 `php .tools/bin/check.php`, HTTP 검증은 [스모크 테스트 기준](smoke-test.md)을 따른다. 지원 PHP 8.3 이상과 설치 DB를 사용하는 검증을 릴리스 판단 기준으로 삼는다.

## 일회성 DB 정리 완료

2026-09-05 기존 설치의 퀴즈·설문 테이블 26개와 관련 설치·설정 기록에 대해 사용자가 삭제 완료 안내를 확인했다. 이후 메인 진입점의 임시 실행 블록과 삭제 코드 파일을 제거했다. 현재 초기화면은 DB 삭제 작업을 실행하지 않는다.

완료 표시인 `sr_site_settings`의 `maintenance.quiz_survey_removed_20260905 = done`은 기록으로 남으며, 이를 읽거나 실행을 재개하는 코드는 없다. 공통 자산·결제·감사 원장과 업로드 파일은 이 정리의 삭제 대상에 포함하지 않았다. 다른 설치의 DB가 자동으로 정리되는 것은 아니므로 위 기존 설치 처리 절차는 계속 적용한다.
